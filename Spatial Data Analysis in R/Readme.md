# Readme
This folder contains some materials for the workshop 'Spatial Data Analysis in R'.

Most of the spatial datasets used in this workshop are too large to be uploaded on Github. To replicate the analysis, they have to be downloaded from their original sources:

Countries and cities: https://www.naturalearthdata.com/downloads/10m-cultural-vectors/

The Consistent and Corrected Nighttime Light dataset (CCNL): https://zenodo.org/records/6644980

The population data for North Korea: https://hub.worldpop.org/geodata/summary?id=74005 

The population data for South Korea: https://hub.worldpop.org/geodata/summary?id=74021
